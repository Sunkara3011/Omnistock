# Omni-Stock Retail - Multi-Warehouse Inventory Control & Stock Reconciliation System

## Project ID
PS017

## Business Use Case

Omni-Stock Retail requires a multi-warehouse inventory control platform
to track physical stock levels and streamline order fulfillment workflows
across regional distribution hubs.

## Core Requirements

- JWT authentication
- Product catalog management
- Multi-warehouse inventory tracking
- Order placement
- Automatic stock updates
- Low-stock replenishment alerts
- Product management by warehouse managers
- Service discovery using Eureka
- API Gateway
- Load balancing
- Inter-service communication
- Transactional consistency
- Unit testing
- Integration testing
- Deployment

## Microservices

1. Auth Service
2. Product Service
3. Inventory Service
4. Order Service
5. API Gateway
6. Eureka Server
